# Contributing

caddy/ui welcomes improvements to its software, explanations, and language support.
Choose the path that matches what you would like to improve:

| Path | A good first contribution | Start here |
|------|---------------------------|------------|
| Codebase | Reproduce a bug, improve an existing view, or add a focused test | [Codebase onboarding](contributing-codebase.md) |
| Documentation | Fix an unclear setup step, add an example, or explain a special case | [Documentation onboarding](contributing-documentation.md) |
| Localization | Translate a small set of related UI strings into a language you know | [Localization onboarding](contributing-localization.md) — available after the foundation is merged |

Documentation changes can start in GitHub's browser editor. Code changes and local
previews use a checkout of the repository. The onboarding pages explain the files
to edit, how to check your work, and what to include in a pull request.

Keep your first change small enough for someone else to review easily. For a larger
feature or documentation reorganization, open an issue describing the intended
result before doing substantial work.

Found a problem but cannot fix it yet? Include the steps to reproduce it, your
caddy/ui version, what you expected, and what happened in a
[GitHub issue](https://github.com/zackwag/caddy-ui/issues).
